## Main user journeys
**Sign up / log in:** nav -> auth modal (`components/auth-modals.html`) -> email+password or Google ->
Supabase session -> `profiles` row loaded (`auth.js`) -> first time: username setup -> daily-login XP RPC.
Visiting a protected page while logged out opens the modal and returns to the page after login.

**Learn:** `/tutorials` -> pick course -> chapter list -> chapter content -> `track_chapter_view` / `chapter_progress`.

**Solve a CTF:** `/rooms` -> pick challenge -> room view (description, hints, lab link) -> open lab page ->
lab backend `/api/lab/<name>` (per-player instance) -> find flag -> submit via `submit_ctf_flag` RPC ->
points/XP awarded, `ctf_solves` row, leaderboard updates. Hints cost XP via `unlock_ctf_hint`.

**Use a tool:** `/tools` -> tool page (login) -> `fetch('/api/<tool>/...')` + Bearer -> server verifies token,
checks `tool_settings.is_enabled`, rate limits, runs, logs to `tool_usage_logs`.

**Admin:** secret panel URL -> Supabase login as admin -> sections (users, CTF, courses, blog, community,
tools on/off, security logs, IP blocks, backups, broadcasts...). All writes go through RLS/RPC admin checks.

## Cross-cutting UI
Navbar with search (`js/search.js`), language switcher (`i18n.js`, `translate.js`; hi, en, bn, pa, te, ta, mr),
scroll-reveal animations (`reveal.js`), maintenance-mode switch (`config.js`).
